# Application

APP-01 builds station selection, observed bike/dock availability, forecasts, and visible freshness indicators. Define the serving contract with ML-01 and show useful loading, error, and stale-data states.

Forecasts come from `ba882-bluebikes-pipeline.ml_models.station_forecasts`. The columns, time windows, example queries and display guidance are in the [forecast serving contract](../docs/ml/forecast-serving-contract.md).
