# Data sources

ING-01 validates Bluebikes GBFS station information/status. ING-02 validates historical trip publications. ING-03 selects historical/forecast weather.

For each source, record its authoritative URL, license, schema/version, coverage, source and ingestion timestamps, refresh cadence, rate limits, and missing-data policy. Discover and verify endpoints before implementing clients. Store immutable originals and provenance; prevent future information from leaking into training features.
